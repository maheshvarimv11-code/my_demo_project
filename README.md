# Simple React CRUD App

This project is a simple CRUD (Create, Read, Update, Delete) application built with React and Vite.

## Features

- Add, edit, and delete items in a list
- Clean and simple UI
- Built with functional components and React hooks

## Getting Started

1. **Install dependencies:**

   ```sh
   npm install
   ```

2. **Start the development server:**

   ```sh
   npm run dev
   ```

3. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Project Structure

- `src/App.jsx`: Main app with CRUD logic
- `src/App.css`: Simple styles for the app

---

This project was scaffolded with [Vite](https://vitejs.dev/) and uses React.
